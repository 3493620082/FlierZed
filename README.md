# FlierZed - 传单mod制作工具

## 最新发行版请在 Release 中下载。

FlierZed 是一个用于快速开发《Project Zomboid》（僵毁）B42 版本中**可阅读传单类物品**的辅助工具。

所谓"可阅读"，即在游戏内对这类物品点击**右键**，可以弹窗查看对应的图片与文字内容（类似一张真实传单的正反面：正面是图片，反面或备注区是文字说明）。

通过本工具，你可以集中化管理传单物品的以下数据，并一键生成 mod 所需的脚本与资源文件：

- **物品**：物品 ID、显示名、图标、重量
- **传单图片**：物品对应展示的图片
- **传单备注**：可阅读的文字内容
- **刷新容器**：物品在哪些容器中刷新及刷新几率

## 主要功能

- 可视化新建 / 打开项目，项目名自动以日期时间命名
- 物品 CRUD：新增、删除、编辑物品基础属性
- 图片 / 图标管理：导入 PNG（自动添加 `Item_` 前缀）、右键重命名、预览
- 传单可阅读内容编辑：图片 + 备注文字
- 刷新容器配置：选择容器与刷新几率
- Ctrl+S 一键生成 `Items.txt`、`FlierData.lua`、翻译文件与 `Distribution.lua`

## 技术栈

- 界面：Python tkinter
- 游戏端脚本：Lua（PZ-Simple UI 框架）
